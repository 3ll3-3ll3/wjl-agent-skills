# 套磁邮件写作规则

## 固定主题

默认主题：

`2027推免咨询｜苏州大学数学与应用数学｜王家乐｜科学岛085400电子信息`

若目标项目不是科学岛，应替换最后一段项目名称，但保持“年份 + 推免咨询 + 本科院校专业 + 姓名 + 目标项目”的结构。

## 个人信息核验

GPA、专业排名、课程成绩、奖项、项目经历和联系方式等个人信息，不再从本文档中的旧记录直接套用。起草正式邮件前，应优先从用户连接的 Microsoft Outlook 邮箱中获取最新有效的个人简历和正式成绩单，并据此核验。

当前已确认 Outlook 中存在可用附件：

- `王家乐个人简历r2.pdf`；
- `成绩单.pdf`。

文件名只作为当前识别线索。以后出现新版附件时，以邮箱中最近且明显更新的版本为准。若多个版本无法判断新旧，应先询问用户。

不得继续硬编码历史专业排名 `2/40` 等可能已经过时的个人数值。

## 正文结构

建议按以下顺序组织：

1. 自我介绍：苏州大学数学科学学院数学与应用数学专业、2027届；GPA、专业排名等从 Outlook 最新简历/成绩单核验后填写；
2. 数学统计基础：数学分析、高等代数、实变函数、概率论、数理统计、应用多元分析、数据科学概论等；具体分数若要写，必须先由最新成绩单核验；
3. 竞赛：全国大学生数学竞赛数学A类省一等奖、全国大学生数学建模竞赛省一等奖；
4. 20% 个性化：只写与目标导师当前研究方向直接相关的衔接；
5. 诚实说明需要补足的算法、工程或专业知识；
6. 用一句话概括大创和数模经历，不展开具体项目；
7. 表达对目标学校和目标项目机会的重视；
8. 直接询问目标项目当年推免硕士名额、数学背景适配性和后续交流机会；
9. 附件说明；
10. 简洁签名。

## 推荐诚意表达

申请中国科学技术大学时，默认可使用：

> 目前我尚未获得华五高校的录取机会，而中国科学技术大学一直是我非常向往的学校，因此我格外珍惜此次申请的机会，也非常希望能够有机会在科大学习和科研。

不要继续扩展成过度“卖惨”的表达。

## 项目经历限制

默认只写：

> 本科期间也参加过国家级大学生创新项目和数学建模竞赛，对数据分析、机器学习和数学建模有一定接触。

除非用户针对某位导师明确要求，不展开：

- LBM；
- Black-Scholes 方程；
- Chapman–Enskog；
- NIPT；
- K-means++；
- Logistic；
- 遗传算法；
- 具体建模论文技术流程。

## 个性化方向示例

### 机器学习 / CV

强调高等代数、概率统计、多元分析、高维数据、矩阵方法，以及愿意补 PyTorch、OpenCV、Linux、Git。

### 多源融合 / 状态估计

强调概率统计、线性代数、动态系统建模、Kalman 相关学习兴趣。

### 机器人

不要把自己写成机器人背景学生。强调希望走智能感知、状态估计、轨迹预测、决策与算法一侧，并承认需要补控制、机器人学、ROS/C++。

### 健康数据 / 医疗 AI

强调概率统计、多元分析、风险预测、复杂数据建模、机器学习。

### 遥感 / 高光谱

强调高维数据分析、模式识别、概率统计、分类预测、多模态数据。

### 农业智能 / 知识工程

强调数据分析、机器学习、知识建模、预测决策；如果导师偏硬件或装备，明确希望做算法和数据侧。

## 禁止事项

- 不虚构熟练掌握 PyTorch、C++、ROS、SLAM 等；
- 不把数值计算写成首要兴趣；
- 不把导师旧方向当成当前方向；
- 不使用“老师您的研究与我完全一致”这类夸大表述；
- 不写过长的项目细节；
- 不群发、不 CC、不 BCC；
- 不在首封邮件里催促或要求明确承诺；
- 不使用未经 Outlook 最新简历/成绩单核验的旧 GPA、旧排名或旧课程成绩；
- 不把简历、成绩单原件提交到公开 GitHub 仓库。

## 附件获取与附件句

默认附件必须从用户连接的 Microsoft Outlook 邮箱中实时取得，而不是默认使用聊天上传文件或仓库文件。

推荐流程：

1. 搜索近期由用户本人发送、且带附件的推免/套磁邮件；
2. 列出候选邮件附件；
3. 选择最新有效的“个人简历”PDF和“成绩单”PDF；
4. 分别获取邮箱附件文件引用；
5. 用这些文件引用创建草稿或发送邮件；
6. 不把 Outlook message id、attachment id、临时下载链接或文件引用持久化到 GitHub。

默认附件句：

> 随信附上我的个人简历和苏州大学正式成绩单，恳请老师在方便时审阅。

如果 Outlook 连接不可用，应先说明并要求恢复连接。除非用户明确授权，不自动改用聊天中的旧附件。
