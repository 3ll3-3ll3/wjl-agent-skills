# Agent 执行说明

本 Skill 以 `SKILL.md` 作为唯一执行真源。

## 核心不变量

1. 先读 `data/science-island-2027-outreach.yaml`，再找新导师或起草首封邮件；
2. 已联系导师默认禁止重复发送首封邮件；
3. 动态招生信息必须重新核验，不沿用旧网页结论；
4. 套磁邮件按“约 80% 固定 + 20% 个性化”执行；
5. 不把用户包装成代码/机器人/硬件背景学生；
6. 不把数值计算作为首选研究兴趣；
7. 邮件只有在用户明确授权发送后才能调用邮箱写操作；
8. 发送必须逐封单独发送，默认无 CC、无 BCC；
9. 回信必须先读完整线程，再分类和起草；
10. 不向仓库提交完整邮件正文、Outlook message id、用户密码、令牌、浏览器会话、简历或成绩单原件。

## 状态文件维护

`data/science-island-2027-outreach.yaml` 是用户明确要求随 Skill 版本化维护的去重基线。允许记录：

- 导师姓名；
- 联系日期与批次；
- 公开研究方向摘要；
- 已发送/回信/关闭等状态；
- 简短回信摘要和后续行动。

不得记录邮件系统内部 ID、完整私人邮件正文、认证信息或原始附件。

新增联系人或回信状态时，保持字段风格一致，并同步更新 `statistics`。
