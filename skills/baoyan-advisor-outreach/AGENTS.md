# Agent 执行说明

本 Skill 以 `SKILL.md` 作为唯一执行真源。

## 核心不变量

1. 先读 `data/` 下所有 `*-outreach.yaml` 历史表，再找新导师或起草首封邮件；
2. 已联系导师默认禁止重复发送首封邮件，且必须跨项目、跨 Outlook/Gmail 去重；
3. 动态招生信息必须重新核验，不沿用旧网页结论，尤其是标注“持续更新”的导师名单；
4. 套磁邮件按“约 80% 固定 + 20% 个性化”执行；
5. 不把用户包装成代码/机器人/硬件背景学生；
6. 不把数值计算作为首选研究兴趣；
7. GPA、专业排名、课程成绩等个人数值信息必须从最新个人简历和正式成绩单核验，不继续硬编码旧值；
8. 套磁邮件实际附带的个人简历和成绩单必须使用用户当前确认或最新核验的有效版本，不默认使用聊天上传旧文件；
9. 邮件只有在用户明确授权发送后才能调用邮箱写操作；
10. 发送必须逐封单独发送，默认无 CC、无 BCC；
11. Gmail 发送后按当前项目和专业领域维护标签；
12. 回信必须先读完整线程，再分类和起草；
13. 不向仓库提交完整邮件正文、Outlook/Gmail message/thread id、attachment id、临时下载链接、用户密码、令牌、浏览器会话、简历或成绩单原件。

## 当前结构化历史表

- `data/science-island-2027-outreach.yaml`：中国科学技术大学研究生院科学岛分院 2027 推免历史；
- `data/iat-2027-outreach.yaml`：中国科学技术大学国家卓越工程师学院（先进技术研究院）2027 推免专业学位硕士历史。

新增项目时应在 `data/` 下新增独立 `*-outreach.yaml`，不要把不同项目混进同一表。

## 附件规则

- 优先使用用户当前明确指定的最新版简历和成绩单；
- 若需从邮箱恢复附件，搜索近期由用户本人发出的、带附件的推免或套磁邮件；
- 确认候选邮件同时包含个人简历 PDF 与成绩单 PDF；
- 2026-09-16 先研院两批实际使用文件名为 `王家乐个人简历r2.pdf` 与 `成绩单.pdf`，仅作历史记录，不视为永久最新版；
- 多版本无法判断时先询问用户，不猜测；
- 任何邮箱内部 ID、临时链接和附件原件都不得写入仓库。

## 状态文件维护

项目数据文件是用户明确要求随 Skill 版本化维护的去重基线。允许记录：

- 导师姓名；
- 公开工作邮箱；
- 项目、专业代码与专业名称；
- 联系日期、批次与发送渠道；
- 公开研究方向摘要；
- Gmail 项目/专业标签；
- 已发送/回信/关闭等状态；
- 简短回信摘要和后续行动；
- 历史批次使用的附件文件名。

不得记录邮件系统内部 ID、完整私人邮件正文、认证信息或原始附件。

新增联系人或回信状态时，保持字段风格一致，并同步更新对应项目的 `statistics`。
