# Agent 执行说明

本 Skill 以 `SKILL.md` 作为唯一执行真源。

## 核心不变量

1. 先读 `data/science-island-2027-outreach.yaml`，再找新导师或起草首封邮件；
2. 已联系导师默认禁止重复发送首封邮件；
3. 动态招生信息必须重新核验，不沿用旧网页结论；
4. 套磁邮件按“约 80% 固定 + 20% 个性化”执行；
5. 不把用户包装成代码/机器人/硬件背景学生；
6. 不把数值计算作为首选研究兴趣；
7. GPA、专业排名、课程成绩等个人数值信息必须优先从 Outlook 中最新个人简历和正式成绩单核验，不继续硬编码旧值；
8. 套磁邮件实际附带的个人简历和成绩单默认从用户连接的 Outlook 邮箱实时获取最新有效版本，不默认使用聊天上传旧文件；
9. 邮件只有在用户明确授权发送后才能调用邮箱写操作；
10. 发送必须逐封单独发送，默认无 CC、无 BCC；
11. 回信必须先读完整线程，再分类和起草；
12. 不向仓库提交完整邮件正文、Outlook message id、attachment id、临时下载链接、用户密码、令牌、浏览器会话、简历或成绩单原件。

## Outlook 附件规则

- 优先搜索近期由用户本人发出的、带附件的推免或套磁邮件；
- 确认候选邮件同时包含个人简历 PDF 与成绩单 PDF；
- 当前可识别的文件名线索包括 `王家乐个人简历r2.pdf` 与 `成绩单.pdf`，但以后出现新版时优先使用更新版本；
- 通过邮箱附件接口获取文件引用后，再用于草稿或发送；
- 多版本无法判断时先询问用户，不猜测；
- Outlook 不可用时应明确说明，除非用户授权，不自动退回使用聊天中的旧附件；
- 任何邮箱内部 ID、临时链接和附件原件都不得写入仓库。

## 状态文件维护

`data/science-island-2027-outreach.yaml` 是用户明确要求随 Skill 版本化维护的去重基线。允许记录：

- 导师姓名；
- 联系日期与批次；
- 公开研究方向摘要；
- 已发送/回信/关闭等状态；
- 简短回信摘要和后续行动。

不得记录邮件系统内部 ID、完整私人邮件正文、认证信息或原始附件。

新增联系人或回信状态时，保持字段风格一致，并同步更新 `statistics`。
