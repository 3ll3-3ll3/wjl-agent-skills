# 自然语言示例

这些示例用于说明预期回复结构，不要求逐字照搬。

## 手动处理 MissAV 与 Twitter

用户：

```text
使用 LoveAV 处理我上传的三个 Telegram HTML。
MissAV 来源提取番号，Twitter 来源提取博主；排除 MissAV 主体库已有记录，返回番号、番号链接、博主名和主页链接。
```

预期行为：

1. 预览全部文件，并展示识别到的来源与数量。
2. 只有来源未绑定或确实存在歧义时才询问用户。
3. 使用当前规则版本独立处理选中的来源。
4. 分别返回番号、番号链接、博主名、主页链接四个可复制列表，同时报告新增、历史、重复、无效与错误数量。

## 规则管理

用户：

```text
把这个 Miss_AV.html 导入为新的参考女优 Tag 库，并把两层黑名单分别预览。
```

预期行为：

- 先展示提取出的标签、重复项、边界标签清理结果与两层黑名单影响。
- 只有用户明确确认后才提交。
- 提交后创建新的不可变规则版本，并刷新可编辑 TXT 镜像。

## 数据查询

用户：

```text
查找所有包含 ABF 的 MissAV 结果，只返回番号，一行一个。
```

预期行为：

- 调用带过滤条件的结果查询。
- 排除已删除行。
- 返回纯文本代码块，代码块内部不放项目符号或解释文字。

## 同一输入容器与自适应复核

用户：

```text
用 LoveAV 处理这个 CSV，运行 MissAV、Twitter、Bad.news 和海角；不要把不确定的格式直接丢掉，列出可疑项并说明证据。
```

预期行为：

1. 同一个输入容器同时运行四个所选工具。
2. 分开返回已接受、已排除、`review` 和错误数量。
3. 遇到新候选形状时，只提出最小确认问题。
4. 最多创建规则建议；不得静默激活已学习规则。

## 旧版联网能力按需启用

用户：

```text
使用已经配置好的个人 Telegram 适配器，读取“番号群”今天 09:00 之后的新消息，但先只生成预览，不要标记已读。
```

预期行为：

- 先检查适配器能力与安全存储状态。
- 预览来源和时间范围。
- 在任何标记已读或其他远程副作用前停止。
- 如果适配器不存在，明确说明当前可用路径是手动导出并上传文件。

## Whos.tv 增量抓取

用户：

```text
接着上次记录抓到今天最新。
```

预期行为：

1. 读取 `whostv-state.json`。
2. 使用 `/helps/10250` 生成增量控制台脚本。
3. 把脚本追加到 `whostv_scripts.md` 最前面。
4. 报告生成的 `.js` 路径和预期 JSON 文件名。
5. 在返回 JSON 通过确定性整理器校验前，不更新截止点。

## Whos.tv 返回 JSON

用户：

```text
整理 whos_tv_solved_answers_since_2026-08-27.json。
```

预期行为：

1. 运行整理器。
2. 只有数量、页码、答案、URL、截止点与顺序全部通过时，才生成按 Asia/Shanghai 日期命名的 Markdown。
3. 报告四类数量和纯番号数量。
4. 成功后再把截止点推进到第一条记录的 pathname。
