# v0.1.3

Fix qasync task re-entry during first Telegram login and other async GUI dialogs.

- Windows/Clash system proxy support from v0.1.2 remains unchanged.
- Phone, verification-code and 2FA dialogs now use non-blocking Qt dialogs awaited through the existing qasync event loop.
- API settings, reset-login confirmation, export result messages and error dialogs use the same qasync-safe approach.
- Regression tests reject blocking modal dialog APIs in the async GUI implementation.
