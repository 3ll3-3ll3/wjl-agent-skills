# v0.1.6 — TG Exporter

本版本将用户可见产品名称缩短为 **TG Exporter / TG 导出器**。

## 变化

- Windows 窗口标题改为 `TG 导出器`。
- QApplication 名称改为 `TG Exporter`。
- PyInstaller 产物改为 `TGExporter.exe`。
- Release 资产改为：
  - `TGExporter-v0.1.6-windows-x64.exe`
  - `TGExporter-v0.1.6-windows-x64-portable.zip`
  - `SHA256SUMS.txt`
- Python distribution name 改为 `tg-exporter`。
- 新 CLI：`tg-exporter`；旧 `telegram-multi-chat-exporter` 暂时保留兼容。

## 兼容性

为了让已有用户升级后继续复用 Telegram Session、API 设置、工作群选择、checkpoint 和日志，以下内容**不改名**：

```text
Python module: telegram_exporter
%APPDATA%\TelegramMultiChatExporter\
```

这次只缩短品牌和发布文件名，不改变导出语义、Telegram API 行为、未读/已读策略或 JSON 格式。
