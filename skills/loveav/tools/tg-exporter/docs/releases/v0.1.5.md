# v0.1.5

## Telegram account chat-folder filtering

- `选择群组` now reads the account's existing Telegram chat folders (Dialog Filters).
- The selector has a `Telegram 分组` dropdown plus the existing name / `@username` search.
- Selecting a Telegram folder narrows the list before checking working groups.
- Dynamic Telegram folder rules are evaluated for eligible groups/channels, including group/channel type and `exclude_read` / `exclude_muted` / `exclude_archived` behavior.
- Explicit include/pinned peers are treated as always included unless explicitly excluded.
- Folders containing no eligible groups/channels are omitted from this exporter-specific selector.
- If folder loading fails, the existing full catalogue/search selector still works.

## Reliability

- Includes the shutdown/disconnect hotfix already present on `main`: Telethon `disconnect()` may either return an awaitable or complete synchronously during qasync/Qt shutdown.
- Shutdown cleanup errors remain log-only and should not become PyInstaller fatal exception dialogs.
