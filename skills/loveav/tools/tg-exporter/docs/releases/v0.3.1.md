## Fixes

### Packaged `--url-domain`

- replaced fragile runtime IDNA codec lookup with explicit offline stdlib IDNA normalization;
- strict hostname/URL validation;
- exact host or subdomain matching only;
- malformed input returns `INVALID_ARGUMENT`;
- no network/public-suffix dependency;
- frozen `tgctl.exe` gets `encodings.idna` defense in depth;
- packaged standalone and portable search-filter smoke cover domain behavior.

### Bounded `--regex` search

- local bounded regex filter for `messages search`;
- case-insensitive by default, `--case-sensitive` optional;
- invalid/empty/overlong patterns rejected before Telegram work;
- max pattern length 512;
- regex + case-sensitivity are included in cursor query binding;
- composes with contains/domain/sender/sender-role/time/type/topic filters.

### GUI normal-close runtime error

- cleanup begins from last-window close while the qasync loop is still alive;
- GUI init/job-monitor/heartbeat tasks are cancelled and awaited;
- GUI detaches only its own daemon lease;
- shared daemon is not shut down by normal GUI close;
- genuine shutdown failures remain visible instead of being swallowed.

### Sender / owner diagnostics

- sender classification uses Telegram-provided peer fields only;
- actual sender stays separate from `forward_origin`;
- unresolved sender remains `unknown` with `unknown_reason`;
- owner visibility distinguishes permissions, participant availability, pagination and Telegram-not-returned cases.

### Additional regressions

- `+08:00` ↔ UTC since/until boundary equivalence;
- two GUI leases + tgctl coexistence in synthetic daemon tests;
- zero-current-unread returns valid empty JSON without full-history scan/read-ack;
- proxy safe-label/privacy boundary.

## Release build policy

The formal Release is rebuilt from the merged `main`; Candidate binaries are not re-labeled as Production. The Release workflow refuses to overwrite an existing tag or Release and produces:

```text
TGExporter-v0.3.1-windows-x64.exe
TGExporter-v0.3.1-windows-x64-portable.zip
tgctl.exe
SHA256SUMS.txt
```

Formal Release hashes are the values in the published `SHA256SUMS.txt`, not Candidate hashes.

## Safety boundaries unchanged

This release does not expand Telegram write permissions. Reader defaults remain read-only. Real send/forward, read acknowledgement, confirmed media download, group mutation, FloodWait stress and Session reset are not implicitly authorized by publishing v0.3.1.

The existing `v0.3.0` tag/Release must not be moved, overwritten, deleted or rebuilt in place.
