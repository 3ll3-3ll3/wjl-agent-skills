# TG Exporter v0.1.7

群组选择器可用性更新，面向账号里有大量群组/频道的场景。

## 新增

- “选择群组”每条记录显示约 42 px 圆形群头像。
- 行高提升到约 58 px，并使用双行信息：群名 + `@username` / 群组或频道 / 未读数。
- 无头像或尚未加载时显示稳定的圆形首字占位。
- 头像只对当前屏幕附近可见项按需异步加载，最大并发 6。
- 成功头像仅缓存在本机 `%APPDATA%\TelegramMultiChatExporter\cache\avatars\`，默认约 7 天。

## 边界

- 群头像只用于选择器 UI，不进入 `result.json`，不复制到导出目录。
- 聊天消息仍然只导出 text/caption，不下载聊天里的照片、视频、文件、语音或贴纸。
- 头像加载失败只回退到首字占位，不影响 Telegram 登录、群组选择和消息导出。
- Telegram Folder、搜索、focused workspace、三种导出模式和 Option B 已读策略均保持不变。

## 验证

发布前要求：

- `pytest -q`
- GUI import check
- Windows one-file PyInstaller build + packaged smoke-test
- Release one-file + portable 两种构建 smoke-test

真实账号仍需验证：头像是否正确对应群组、滚动/分组/搜索切换是否流畅，以及无头像群是否正常显示首字占位。
