# TG Exporter v0.1.9

本版新增 **Codex 可调用的本地 Telegram CLI Bridge：`tgctl`**，同时保留 v0.1.8 GUI/导出能力。

## 新增

- `tgctl status --json`：安全账号状态，不输出 phone/api_hash/验证码/2FA/Session 内容。
- `tgctl chats list`：支持 Telegram Chat Folder、关键词、limit 和纯 JSON 输出。
- `tgctl messages search`：按 chat、关键词、since/until、limit 搜索 text/caption。
- `tgctl messages get`：按 message_id 获取指定消息，转发前可重新确认。
- `tgctl forward`：使用 Telethon 真正 forward，支持 `--to me` Saved Messages。
- `tgctl send`：纯文本发送，`parse_mode=None`。
- forward/send 均支持 `--dry-run`。
- forward 默认单次最多 20 条；显式 `--allow-large-batch` 后最多 200 条。
- FloodWait 结构化返回，不自动疯狂重试。
- 同名 chat 不静默选择，返回 `AMBIGUOUS_CHAT` 和候选 chat_id。
- JSON 成功/失败 envelope 与稳定错误码/退出码，适合 Codex 判断结果。
- GUI 与 tgctl 共享 Session OS 锁；第一版不允许两个进程同时打开同一 Telethon SQLiteSession，冲突返回 `SESSION_BUSY`。
- CLI 复用 `%APPDATA%\TelegramMultiChatExporter\telegram.session`、`api_credentials.json` 和现有 Windows system proxy detection；不会重新要求用户在 CLI 输入手机号/OTP/2FA。
- Telegram write 日志只记录动作、chat/message id、数量和结果，不记录消息正文。

## 第一版边界

本版不包含 MCP、后台 daemon、24/7 监听、自动转发规则、Bot API、AI 分类器、联系人/群管理、媒体发送/媒体转发或聊天媒体下载。

CLI 真实 Telegram 写操作 CI 仅使用 mock；正式发布后仍需要用户在真实 Windows 账号上优先以 Saved Messages 完成 forward/send E2E。
