# 保持原格式的填写流程

## 准备

1. 判断每个输入是模板、证明材料、项目页面还是既往示例。
2. 保留未修改原件。没有覆盖授权时，创建以 `_已填写` 结尾的同目录副本。
3. 编辑前完整检查分节、页面尺寸、页眉页脚、段落、表格、合并单元格、图形、字段、控件、公式、打印区域和页数。
4. 为每个目标字段记录来源与置信度：当前项目明确事实、私有档案已核实事实、匹配口径的证明事实或待确认。

## Word

- `.docx` 应直接编辑既有 OOXML 元素，保留运行属性，并继承目标占位符格式。
- 能做局部替换时，不整体清空段落或单元格。
- 保留内容控件、书签、域代码、图片关系、表格拓扑、合并单元格、行高和分节属性。
- 旧版 `.doc` 使用已安装的 Office/WPS 转换能力或经过验证的 Apache POI HWPF 流程。必须保留单元格结束标记；普通回车会拆分表格时，使用单元格内换行符。
- 不得仅为方便编辑而把旧格式改造成明显不同的文档。

## Excel

- 保留工作簿类型、工作表、公式、名称、合并区域、行列尺寸、边框、填充、数字格式、打印区域、页面设置、隐藏行列、数据验证和宏。
- 只写入已映射的输入单元格。除非用户明确要求，不排序、不规范化、不重构工作簿。

## PDF

- 可填写 PDF 优先使用既有 AcroForm 字段。
- 不可填写 PDF 在测量后的坐标上叠加文字和图片，保留原页面和页面框。
- 除非没有可靠编辑路径，不得从零重建 PDF；不可避免的保真限制必须在交付前说明。

## 日期

- 填表日期、申请日期、承诺日期、申请人签名旁日期以及等价的申请人完成日期，统一使用任务执行当天的 `Asia/Shanghai` 日历日期。
- 严格匹配模板中分开的年、月、日框和既有格式；没有示例时使用 `YYYY年M月D日`。
- 即使手写或电子签名暂时为空，申请人日期仍然填写。
- 不得倒签，也不得复制旧申请日期，除非用户明确指定该日期。
- 出生、学习、毕业、考试、获奖、项目、工作和截止日期必须来自已核实事实或当前项目来源。
- 学校、院系、审核人、推荐人、用人单位、盖章或机构意见区的日期留空，除非用户明确授权填写该方区域，并在交付报告中列出。

## 文字适配

内容放不下时按以下顺序处理：

1. 使用更短但准确的表达；
2. 使用含义明确的规范缩写；
3. 沿用目标区域的自动换行；
4. 只对新增文字小幅、统一缩小字号；
5. 仅在用户同意或模板允许扩展时调整布局。

不得为了腾出空间而删除标签、说明、承诺或其他模板内容。

## 签名和选项

- 签名、印章、机构意见、负责人姓名和机构日期默认留空。
- 电子签名是可用素材，不是持续授权；每份文件都需要用户明确要求后才能插入。
- 只有档案或用户当前说明支持时才勾选事实选项。
- 政治、法律、纪律、健康、宗教、婚姻和推免资格声明需要明确证据或用户确认。

## 验证

1. 保存后用对应格式解析器重新打开，确认文件未损坏。
2. 与原件比较结构不变量：分节数、页面设置、表格与行列拓扑、合并区域、工作表名称、公式或 PDF 页面框。
3. 使用对应 Word、Excel 或 PDF 工作流渲染全部页面或工作表视图。
4. 在正常阅读比例检查裁切、溢出、乱码、图片错位、表格破坏、分页变化、公式错误，以及文字是否遮挡签名或盖章区。
5. 发现问题后修改并重新渲染，直到清晰无误。旧格式确实无法渲染时，执行最强可用结构检查并说明限制。
6. 最后检查没有猜测字段，也没有把旧项目的学校、专业、导师或日期带入当前输出。
