# 个人陈述工作流

仅在任务涉及个人陈述、个人自述、申请动机、研究计划或相近材料时读取本文件。

## 输入与约束

1. 读取当前任务中的院校、院系、专业、培养层次、方向和导师信息，并从官方项目来源提取字数、语言、栏目、模板、文件格式与命名要求。
2. 读取 `profile.local.md` 和 `personal-statements.local.md`。目录中的所有既有陈述均可作为参考，但优先使用与当前方向接近、事实较新且正文完整的版本；对重复的 DOCX/PDF/合并材料只保留一份内容参与综合。
3. 用户当前明确说明和官方项目要求优先于既有稿件。旧稿中的排名、GPA、奖项、日期、学校、项目、导师、实验室和研究方向都要重新核实。
4. 若院校、专业或方向缺失到无法定向写作，询问缺失项；若仅导师未知，则写成不依赖具体导师的版本，不自行猜测。

## 内容生成

- 从已核实事实中选择与目标方向最相关的课程、项目、竞赛、科研训练、技术能力、荣誉和发展目标，不必把所有经历都塞入一篇陈述。
- 可重新组织叙事、改写表达、补充自然的过渡与对未来学习的规划，但不得新造论文、科研成果、实习、排名、奖项、技能熟练度或与导师的联系。
- 数学、统计、数据科学、人工智能、机器人等方向应使用不同的经历权重和研究兴趣表述，体现真实的专业适配，而不是只替换院校名称。
- 目标项目的课程、平台、研究特色或培养方式只有在官方来源中核实时才可写入。避免空泛吹捧，也不要声称已经加入某实验室或得到导师认可。
- 保持第一人称、具体、克制且连贯。默认包含学术基础、相关经历、方向动机、项目匹配和未来规划；模板另有栏目时服从模板。
- 旧稿可以提供个人表达偏好与素材线索，但最终稿应针对当前项目形成独立文本，避免大段照搬单一旧稿。

## 输出

1. 用户提供模板时，在模板内填写并尽量保持原格式；用户未提供模板时，制作简洁正式的 A4 文档并输出 PDF。
2. 无明确字数要求时，根据材料充实度控制在约 1000 至 1500 个中文字符；英文稿默认约 700 至 1000 词。此范围只是默认值，不能覆盖项目要求。
3. 默认文件名为 `王家乐_<院校>_<专业或方向>_个人陈述.pdf`。当前任务给出的文件名格式优先。
4. 生成 PDF 后逐页渲染检查，确保字体正常、段落无裁切、分页自然、页眉页脚与模板一致，并核对文中只出现当前申请项目。
5. 交付时简要说明采用的目标方向、字数和仍需用户确认的事实，不输出无关的个人敏感信息。
